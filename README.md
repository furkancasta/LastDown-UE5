# 📹 LastDown-UE5

<p align="center">
  A retro-inspired "Found Footage" psychological horror simulation.
</p>

## 🔦 Project Overview
**LastDown** is a psychological horror experience built with Unreal Engine 5, designed to feel like watching a lost video recording. Unlike traditional horror games, this project focuses on a "Found Footage" simulation where the player experiences a terrifying journey through the lens of a handheld camera. 

There are no game-y mechanics like health bars or battery management; the focus is entirely on immersion, psychological dread, and the unsettling feeling of rewatching someone's final moments.

## 📼 Key Features
* **Found Footage Simulation:** Designed to look and feel like a real VHS recording. No UI/HUD to break the immersion.
* **Retro Aesthetic:** Heavy use of PSX-style low-poly assets, dithering, and VHS artifacts to create a grainy, nostalgic, and disturbing visual style.
* **Handheld Camera Movement:** Realistic camera shake and movement that mimics someone walking through a high-stress environment.
* **Atmospheric Realism:** A heavy focus on environmental storytelling where the world itself tells the story through lighting and sound.
* **Psychological Horror:** A slow-burn experience that relies on atmosphere and "unseen" threats rather than combat.

## 🛠️ Technical Details
* **Engine:** Unreal Engine 5.x
* **Art Style:** Retro / PSX / Found Footage (VHS)
* **Lighting:** Lumen-driven dynamic lighting to enhance the grainy, low-light video feel.
* **Post-Processing:** Custom materials for the signature retro-video look.

## 💻 Installation & Running
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/furkancasta/LastDown-UE5.git](https://github.com/furkancasta/LastDown-UE5.git)
    ```
2.  **Generate Project Files:** Right-click `LastDown.uproject` and select "Generate Visual Studio project files".
3.  **Open with UE5:** Launch Unreal Engine 5 and open the `LastDown.uproject`.
